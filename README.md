College Management System (Python)

The College Management System is a Python-based console application designed to manage basic college operations efficiently. It helps in handling student admissions, course information, library details, study resources, and placement packages in an organized manner. The project minimizes manual effort and demonstrates effective use of Python and Object-Oriented Programming concepts.

Features

Student admission management

College campus information

Course and branch details

Library information system

Study resources access

Placement and package overview

Menu-driven and user-friendly interface

Technologies Used

Python

How to Run

Install Python (version 3.x recommended)

Clone the repository

Run the main Python file using:

python college_management_system.py
